## Regeneración de CV (opcional)

Los CV originales se generan con un motor propio de Juan (`content_part.py` + `engine.py` +
`build.py`, con `python-docx` y Chromium headless para el PDF). Si se necesita una variante nueva
o un retoque profundo, se edita el contenido en ese motor y se regeneran DOCX + PDF a la vez.
Para adaptaciones puntuales por oferta basta con reordenar/priorizar contenido ya existente.
